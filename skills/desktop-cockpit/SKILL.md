# Desktop Cockpit 2.0 (ADC 2.0) AI Agent 操作指引

本 Skill 提供 AI Agent 在 Windows 環境下操控桌面應用程式的**零干擾 (Zero-Interference)** 規範。
所有目標應用程式均運行於獨立的 Win32 背景桌面 (`CockpitSecretDesk`)，**使用者的主螢幕完全看不到視窗，實體滑鼠 0 位移、0 奪取焦點**。

---

## 1. 核心工具：`cockpit_cli.py`

在專案目錄 `d:\AntiGravity\Agent-Study\antigravity-desktop-cockpit\` 下，使用 Python 執行 `cockpit_cli.py`：

```powershell
python.exe -X utf8 d:\AntiGravity\Agent-Study\antigravity-desktop-cockpit\cockpit_cli.py <COMMAND> [OPTIONS]
```

### 命令速查表

| 指令 | 說明 | 範例 |
| :--- | :--- | :--- |
| `launch [app]` | 在隔離桌面啟動應用 (預設: `notepad++`) | `python.exe -X utf8 cockpit_cli.py launch notepad++` |
| `capture [-o path]` | 擷取隔離桌面目前畫面至 JPEG 檔案 | `python.exe -X utf8 cockpit_cli.py capture -o screen.jpg` |
| `uia [-d depth]` | 取得目標視窗或當前頂層彈窗之 UIA 語意樹 | `python.exe -X utf8 cockpit_cli.py uia --depth 4` |
| `diff` | 比對快照，偵測動作前後「新出現」的對話框與視窗 | `python.exe -X utf8 cockpit_cli.py diff` |
| `type "<text>"` | 向目標視窗或編輯區注入文字 (支援多語系，零干擾) | `python.exe -X utf8 cockpit_cli.py type "Hello World"` |
| `click "<name>"` | 透過 UIA InvokePattern 靜默點擊按鈕或元件 | `python.exe -X utf8 cockpit_cli.py click "No"` |
| `close` | 向視窗發送 `WM_CLOSE` 關閉訊息 (觸發儲存詢問等) | `python.exe -X utf8 cockpit_cli.py close` |
| `list` | 列出隔離桌面目前所有活動視窗清單 | `python.exe -X utf8 cockpit_cli.py list` |
| `kill [--pid id]` | 強制結束目標隔離進程 | `python.exe -X utf8 cockpit_cli.py kill` |

## 2. 標準自動化流程範例 (Standard Recipe)

當需要操作應用程式完成「啟動 -> 編輯 -> 儲存或關閉」任務時，應依循以下精簡流程：

### 範例：Notepad++ 自動化編輯與未儲存彈窗處理

1. **啟動目標程式**：
   ```powershell
   python.exe -X utf8 cockpit_cli.py launch notepad++
   Start-Sleep -Milliseconds 1000
   ```
2. **文字輸入**：
   ```powershell
   python.exe -X utf8 cockpit_cli.py type "Task content generated by Agent."
   ```
3. **嘗試關閉視窗 (觸發確認彈窗)**：
   ```powershell
   python.exe -X utf8 cockpit_cli.py close
   Start-Sleep -Milliseconds 600
   ```
4. **差異比對 (偵測彈窗)**：
   ```powershell
   python.exe -X utf8 cockpit_cli.py diff
   ```
   觀察回傳 JSON 之 `new_dialogs`。若出現 `#32770` 對話框（如標題 `Save`），代表彈窗已就緒。
5. **靜默點擊按鈕**：
   ```powershell
   # 點擊 "No" (不儲存)
   python.exe -X utf8 cockpit_cli.py click "No"
   ```
6. **確認退出乾淨**：
   ```powershell
   python.exe -X utf8 cockpit_cli.py list
   ```
   若列表為空 `[]`，代表任務圓滿完成且無孤兒進程。

## 3. 注意事項與最佳實踐

1. **零干擾保證**：嚴禁使用物理滑鼠移動或 SendInput 搶奪主螢幕焦點。所有互動一律透過 `cockpit_cli.py` 走隔離桌面通道。
2. **狀態感知優先**：在點擊未知按鈕前，可先呼叫 `uia` 檢視按鈕精確名稱 (`Name`)。
3. **多語言支援**：`type` 指令透過背景 Win32 訊息發送，完美相容中文、英文與特殊符號，不會喚醒實體 IME 候選字框。
